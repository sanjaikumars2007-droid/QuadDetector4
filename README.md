AI Object Detector


About the Project
This project is an image classification model created using Google Teachable Machine.

The model is trained to recognize four classes: 
- 🌊 Ocean
- 🐰 Rabbit
- 🚗 Cars
- 🍾 Bottle

Technologies Used:
- Google Teachable Machine
- Machine Learning
- TensorFlow.js

How It Works:
1. Images are collected and organized into four classes.
2. The model is trained using Teachable Machine.
3. The trained model predicts which class an input image most closely resembles.

Project Objective:
To explore the fundamentals of machine learning and image classification by training a custom AI model.

Future Improvements:
- Create a web interface for testing images.
- Display prediction confidence.
- Improve accuracy using more diverse training images.
- Deploy an interactive web demo.
